Access & Licensing

✓  Free for students, researchers, and faculty members

✓  Complimentary 1-year evaluation license for users of previous versions

Getting your license takes only a few minutes. Follow the steps below:

1

Create a free account

Register at manage.volvicon.com/register. Fill in your name, email, and organization details.

2

Download & install Volvicon

Once logged in, go to Downloads and install the latest version of Volvicon on your machine.

3

Generate your hardware key (.dat file)

Launch Volvicon. When prompted for a license, use the built-in tool to generate your hardware data file (.dat). This file uniquely identifies your machine and is required for the license request.

4

Submit a license request

Go to Licenses → Request New License, select the software, version, and license tier, then upload your .dat file.

🔒

Redeem your complimentary 1-year license

In the Additional Message field of the license request form, include the note:
USER1YEAR
This code entitles previous Volvicon users to a free 1-year evaluation license. Processing is typically completed within 8–24 hours.

5

Apply the license & start using Volvicon

Once approved, download the license file from manage.volvicon.com/licenses and apply it inside Volvicon to activate your seat.
